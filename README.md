# TYPA

社員の目標記入から一次・二次評価、評価結果のPDF出力までを行う人事考課アプリです。

[最新版をダウンロード](https://github.com/tsuchiyoshi-industry/typa/releases/latest)（Windows）・ブラウザ版：[https://typa.tyco.co.jp](https://typa.tyco.co.jp)（Chromebook などはこちら）

## 管理者が最初にすること

1. 配布されたアプリに、社員番号とパスワードでログインします。
2. **「設定」**で、評価期間・配点・通知メールの送信元を設定します。評価する期間の「この期間を開始する」を押します。
3. **「社員マスタ」**で、社員ごとの等級・一次評価者・二次評価者を設定します。一次評価だけで完了する社員は、二次評価者を「なし」にします。
4. 未登録の社員の**「招待コード」**を押し、表示されたコードを本人に個別に渡します。

まだ利用環境や最初の管理者アカウントがない場合は、導入担当者が [初期構築](docs/supabase-setup.md) を行ってください。社員の追加・氏名変更も導入担当者に依頼します。

## 社員に案内すること

初めて使う社員は「新規登録」を選びます。会社メールに届く**認証コード**と、管理者から渡された**招待コード**を使い、社員番号とパスワードを登録します。招待コードは7日間有効・1回限り。紛失・期限切れの場合は再発行してください。

登録後は、社員番号とパスワードだけでログインできます。共有メールも使えます。

## 評価の進め方

**本人が目標を記入・送信 → 一次評価者が目標を確定 → 本人が達成状況を書いて一次評価を依頼 → 一次評価者が評価・確定 → 二次評価者が評価・確定**

- 本人は「評価シート一覧」からシートを作成・記入します。
- 評価者は「部下の評価」から担当するシートを開きます。
- 二次評価者が「なし」の場合は、一次評価者の確定で完了します。
- 確定したシートはPDFに出力できます。管理者は全社の進捗も確認できます。

目標の送信・確定、一次評価の依頼・確定のたびに、次に動く人へ知らせます（アプリ内通知かメール）。失敗した場合は「通知を再送」を使います。詳しい操作はアプリ内の「ヘルプ」を参照してください。

## よくある管理作業

| やりたいこと               | 操作                                                                                   |
| -------------------------- | -------------------------------------------------------------------------------------- |
| パスワードを忘れた         | 社員マスタで「取消」→ 招待コードを発行 → 本人が再登録。評価データは残ります            |
| 退職・休職で利用を止めたい | 社員マスタで「利用停止」。再開するときは「利用再開」                                   |
| 次の評価期間へ進みたい     | 設定で次の期間を作り、「この期間を開始する」。現在の期間の未確定シートを先に確定します |
| 共有PCで使いたい           | 社員マスタの「ログイン」を「閉じたらログアウト」にしておきます                         |

評価者・等級・権限の変更はAdminが行います。Reviewerは社員一覧・評価構造の閲覧と、担当する評価を行えます。
