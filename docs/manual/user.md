# TYPA 利用者マニュアル

評価される社員（被評価者）向けの説明書です。登録・ログインから、評価シートの記入・提出、結果の確認までを、画面に沿って説明します。

部下を評価する人は「評価者マニュアル」、社員や評価期間を管理する人は「管理者マニュアル」もあわせて読んでください。

## 評価の流れ

評価シートは評価期間ごとに1枚作ります。会社が期（年度）を上期・下期などに分けているときは、それぞれの評価期間で1枚ずつ作り、それぞれで評価されます。1枚の評価シートは次の順で進み、あなたが操作するのは「下書き」の間だけです。

```
下書き → 一次評価待ち → 二次評価待ち → 最終評価済み
```

| 状態 | いま誰の番か | あなたができること |
| --- | --- | --- |
| 下書き | あなた | 目標の記入・修正、提出 |
| 一次評価待ち | 一次評価者 | 内容の確認、「下書きに戻す」、「通知を再送」 |
| 二次評価待ち | 二次評価者 | 内容の確認 |
| 最終評価済み | ―（完了） | 内容の確認、PDF 出力 |

二次評価者を置かない社員は、一次評価者の確定で「最終評価済み」になります。あなたの評価者が誰かは、[社員マスタ](#8-自分の評価者を確認する)で確認できます。

## 1. 初めて使うとき（新規登録）

### 用意するもの

| もの | 入手先 |
| --- | --- |
| 社員番号 | 会社から知らされている番号。ログインに毎回使います |
| 招待コード | 管理者から個別に受け取ります。7日間有効・1回限りです |
| メールアドレス | 会社のドメインのアドレス。認証コードを受け取るために使います。共有PCのメールアドレスでもかまいません |

### 手順

1. ログイン画面の「新規登録」を押します。
2. メールアドレスを入力し、「認証コードを受け取る」を押します。会社のドメイン以外のアドレスでは押せません。

![新規登録（メールアドレスの入力）](user/02-register-email.png)

3. メールに届いた**認証コード**、**社員番号**、**招待コード**、**パスワード**（確認用に2回）を入力し、「登録する」を押します。
4. 「あなたの社員番号は〇〇です」と表示されたら、番号を控えて「覚えました」を押します。そのまま評価シート一覧が開きます。

![新規登録（認証コード・招待コード・パスワードの入力）](user/03-register-code.png)

パスワードは**6文字以上で、大文字・小文字・数字をすべて含めて**ください。

> 認証コードと招待コードは別のものです。認証コードは「そのメールを受け取れること」を、招待コードは「その社員として登録してよいこと」を確かめます。どちらも必要です。

| 表示されたメッセージ | 対処 |
| --- | --- |
| 社員番号または招待コードが正しくないか、招待の期限が切れています | 番号とコードを見直し、だめなら管理者に再発行を依頼する |
| 認証コードが正しくないか、有効期限が切れています | 「認証コードを再送する」で新しいコードを受け取る |
| この社員番号は既に登録されています | 登録済みです。ログイン画面からログインする。心当たりがなければ管理者へ |
| この社員番号は登録の途中で止まっています | 前回と同じパスワードで登録し直すか、管理者へ |

## 2. ログインとログアウト

社員番号とパスワードを入力して「ログイン」を押します。メールアドレスはログインには使いません。

![ログイン画面](user/01-login.png)

使い終わったら、右上の自分の名前（ユーザーメニュー）→「ログアウト」を押します。共有PCでは必ずログアウトしてください。初めは全員、アプリを閉じると自動でログアウトする設定になっています。

| こんなとき | どうする |
| --- | --- |
| パスワードを忘れた | 管理者に「登録の取り消し」と新しい招待コードを依頼し、新規登録をやり直す。評価シートは消えません |
| 「利用が停止されています」と出る | 管理者が利用を止めています。再開は管理者に依頼する |
| 社員番号を忘れた | 管理者に確認する |

## 3. 画面の見かた

ログインすると、上部に次のメニューが並びます。

| メニュー | 内容 |
| --- | --- |
| 評価シート | 自分の評価シートの一覧。ふだんはここから操作します |
| 部下の評価 | 評価者になっている人だけが使う画面です。評価する部下がいなければ何も表示されません |
| 社員マスタ | 自分の等級と評価者を確認できます |
| ユーザーメニュー（右上の名前） | ダークテーマの切り替え、ヘルプ、ログアウト |

![ユーザーメニュー](user/12-user-menu.png)

## 4. 評価シートを作る

評価シートは、評価期間ごとに**自分で作成**します。自動では作られません。

1. 「評価シート」を開き、右上の「新規作成」を押します。

![評価シート一覧（まだシートがないとき）](user/04-sheet-list-empty.png)

2. 「評価対象期間」が今回の期間になっていることを確かめ、「評価シートを作成」を押します。

![評価期間を選んで作成](user/05-new-sheet.png)

作成できるのは、管理者が「実施中」にしている評価期間だけです。シートの等級（評価項目）は作成した時点のもので決まります。昇級などで等級が変わる予定があるときは、作成前に管理者に確認してください。

## 5. 目標を書く

作成したシートは「下書き」の状態で開きます。上部に進み具合、その下に自分・評価期間・評価者が表示されます。

![作成直後の評価シート](user/06-sheet.png)

「目標を編集」を押すと、次の3つを入力できます。書き終えたら「目標を保存」を押します。

| 欄 | 書くこと | 記入例 |
| --- | --- | --- |
| チャレンジ目標 | 評価期間の中で目指すこと。数字や期限を入れると評価しやすくなります | 受注処理の手戻りを、半年で月20件から10件に減らす |
| 中間目標 | 期間の途中での目安 | 12月末までに手戻りの原因を分類し、上位3つの対策を決める |
| 達成状況 | 期末に、実際にどこまでできたか | 入力チェック表を作って運用した。3月の手戻りは月9件になった |

![目標の入力](user/07-goal.png)

- 目標が複数あるときは「目標を追加」でタブを増やします。置ける数は画面の「目標は1〜〇件」のとおりです。
- 不要になったタブは「この目標を削除」で消します。チャレンジ目標が空のタブが残っていると提出できません。
- 保存は目標ごとです。保存しておけば、画面を閉じても続きから書けます。保存せずに画面を移ろうとすると確認が出ます。

> 中間目標と達成状況は、期初にまとめて書く必要はありません。期初はチャレンジ目標と中間目標を、期末に達成状況を書き足してから提出します。

### 前の評価期間の目標を続ける

前の評価期間（下期なら同じ期の上期、上期なら前の期の下期）にもシートがあるときは、目標の欄の上に「前の評価期間の目標」が表示されます。前の評価期間の目標と達成状況を見ながら、この評価期間の目標を立てられます。

![前の評価期間の目標](user/15-previous-goals.png)

- この評価期間も続ける目標は「続ける」を押します。チャレンジ目標の文言が、この評価期間の目標に加わります。中間目標と達成状況は、この評価期間の分を書いてください。
- 続けない目標は「済み」として扱われます。空いた目標の枠には、新しい目標を書けます。
- 続けた目標をこの評価期間のシートで削除すると、「済み」に戻ります。
- 続けられるのは下書きの間だけです。

## 6. 提出する

すべて書き終えたら、上部の「提出する」を押します。

![提出の確認](user/08-submit.png)

確認画面の「一次評価者（〇〇）に通知メールを送る」にチェックを入れたままにすると、一次評価者にメールが届きます。「提出する」を押すと、状態が「一次評価待ち」に変わります。

![提出後の評価シート](user/09-submitted.png)

- 提出すると目標は編集できなくなり、評価者に内容が表示されます。**保存しただけでは提出されません。**
- 一次評価者が確定する前なら、「下書きに戻す」で修正できます。直したら、もう一度「提出する」を押してください。下書きの間は、評価者には表示されません。
- 通知メールの送信に失敗しても、提出は済んでいます。「通知を再送」で送り直せます（下の[通知メール](#9-通知メール)を参照）。

## 7. 評価の結果を確認する

評価が進むと、シートの状態が変わります。「評価シート」の一覧で状態を確認できます。

自分のシートの画面では、目標ごとの**一次評価の点数**（1〜4）を確認できます。共通評価・総評・評価点・評価ランクは画面には表示されません。

![最終評価済みの自分のシート](user/11-result.png)

最終評価済みになると、一覧の「PDF出力」が押せるようになります。PDF には、共通評価・総評・評価点・評価ランクを含む評価結果がすべて載ります。確定前は「確定後に PDF 出力」と表示されます。

![評価シート一覧（最終評価済み）](user/10-sheet-list-final.png)

評価ランクは、100点満点の評価点から自動で決まります。

| 評価点 | ランク |
| --- | --- |
| 95点以上 | S |
| 90点以上 | A |
| 80点以上 | B+ |
| 60点以上 | B |
| 50点以上 | B- |
| 40点以上 | C |
| 40点未満 | D |

### 以前の評価期間

一覧の上部のタブで評価期間を切り替えられます。締められた評価期間のシートは、閲覧と PDF 出力だけができます。

会社が「評価をしないまま締める」とした評価期間のシートは、最終評価済みでなくても PDF に出力できます。その PDF では、点数・ランク・評価者のコメントの欄に `***` と表示されます。

### 締め後修正

評価期間を締めた後に、管理担当者が記入内容や評価を直すことがあります。直された項目があると、シートの上部に「締め後修正があります」と赤字で表示され、どの項目が・いつ・どんな理由で・どう変わったかを確認できます。PDF にも赤字で載ります。表示されるのは、あなたが見られる項目の修正だけです。

![締め後修正の表示](user/16-corrections.png)

## 8. 自分の評価者を確認する

「社員マスタ」に、自分の等級・一次評価者・二次評価者が表示されます。評価者が「未設定」のときや、違う人になっているときは管理者に連絡してください。

![社員マスタ（自分の情報）](user/13-profile.png)

## 9. 通知メール

| いつ | 誰に届くか |
| --- | --- |
| あなたが提出したとき | 一次評価者 |
| 一次評価者が確定したとき | 二次評価者 |

どちらも、確認画面でチェックを入れたときだけ送られます。最終評価の確定では、あなたにはメールは届きません。一覧で状態を確認してください。

「一次評価待ち」の間は、あなたが「通知を再送」を使えます。重複送信を防ぐため、失敗した後は1分以上、送信中や結果が分からないときは5分以上あけてから押してください。回数の上限が表示されたら管理者に相談します。再送のためだけに下書きに戻して出し直す必要はありません。

## 10. よくある質問

| 質問 | 答え |
| --- | --- |
| 提出後に内容を直したい | 一次評価の確定前なら「下書きに戻す」で直せます。確定後は変更できないので、評価者に相談してください |
| 途中でやめたい | 目標ごとに「目標を保存」を押してから閉じてください。次に開くと続きから書けます |
| 以前の期間のシートに書き込めない | 締められた期間は閲覧と PDF 出力だけです。今回の期間のシートに書いてください |
| 上期と下期で2回シートを作るの？ | 期を半期に分けている会社では、上期と下期でそれぞれシートを作り、それぞれ評価されます。下期のシートでは、上期の目標を見ながら続けるものを選べます |
| シートに「締め後修正」と出ている | 締めた後に管理担当者が直した項目です。理由も表示されています。内容について分からないことは管理担当者に確認してください |
| 「評価シートを作成」でエラーになる | 作成できるのは「実施中」の期間だけです。期間が始まっているか管理者に確認してください |
| 間違えて2回「新規作成」した | 1つの期間に作られるシートは1枚です。作成済みなら、同じシートが開くだけです |
| 自分の評価点が画面に出ない | 評価点・ランク・総評は、最終評価済みになってから PDF で確認します |
| 入力中にアプリの更新が来た | 先に入力を保存してください。更新は「あとで」を選んで後回しにできます。更新後はアプリが再起動します |

アプリの中にも、ユーザーメニュー →「ヘルプ」に同じ内容の説明があります。

![ヘルプ](user/14-help.png)
